# Huymiles Meilenrechner

A small, browser-based calculator for comparing an award flight with the cash price for the same itinerary.

## Nutzung

Öffne `index.html` im Browser. Du brauchst weder ein Konto noch eine Installation.

1. Gib den Barpreis, die benötigten Meilen und die Zuzahlung ein.
2. Gib das aktuelle Transferverhältnis ein, etwa 5 Punkte für 4 Meilen.
3. Der Rechner zeigt die benötigten Punkte, die Differenz zum Barpreis und den Gegenwert je Punkt.

Beispiel mit frei gewählten Zahlen: 1.800 € Barpreis, 240 € Zuzahlung und 60.000 Meilen ergeben bei einem Verhältnis von 5 zu 4 rechnerisch 75.000 Punkte und 2,08 Cent Gegenwert pro Punkt.

Alle Eingaben bleiben im Browser. Der Rechner enthält keine Flugsuche oder Programmdaten. Mindestmengen und Transferschritte können die tatsächlich benötigte Punktzahl erhöhen.
